# Unreal receiver plugin

See [RGB MoCap Connect](RGBMoCapMetaHuman/README.md) for installation, source
builds, MetaHuman and UE5 mannequin workflows, and security boundaries.
The source tree contains the authored plugin code and documentation. Unreal
Engine and character assets are installed separately. Use the
[matching prebuilt receiver and sender bundle](../docs/UNREAL_LIVE_LINK.md#prebuilt-downloads)
or [build the sender locally](../docs/UNREAL_LIVE_LINK.md#build-the-sender-locally).
